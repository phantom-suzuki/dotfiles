# 用語の選び方

ユーザー向けの文章で使う語の決まり。日本語の組み立て方は `easy-japanese.md` に書いてある。
用語集の本体は `docs/glossary/` にある。常時読み込まないので、迷ったときに自分で開く。

- 日本語の比喩を発明しない。数える単位（枠 / 班 / 波 / 段）も発明しない
- 対象が 1 つに決まる場面で総称語を使わない。対象物の名前で書く
- 標準用語が思い浮かばないときは `docs/glossary/` を引く。分野別に 4 ファイルある

## 頻出の言い換え

| 使わない | 使う |
|---|---|
| 司令塔 / HQ | 統括セッション |
| 枠 / 班 / レーン | 並列セッション / 担当セッション |
| 第 N 波 / 波 N | 第 N 回の実施 |
| 窓 / 窓明け | 作業できる時間帯 / その終了 |
| 第 N 段 / N 段目 | 第 N 工程 |
| 器 / 受け皿 / 束 | 対象物の名前（親要素・まとまり など） |
| leaf | Task Issue / 末端の Issue |
| caller | 環境ごとの設定ディレクトリ |
| 投入 | 何をどこへ取り込むか目的語を書く |
| 検算 | 数え直しての照合 |

## 用語集の使い分け

| ファイル | 引く場面 |
|---|---|
| `docs/glossary/jargon.md` | 内輪語の対応表（全 40 語）。上の表の正本 |
| `docs/glossary/design.md` | 設計・アーキテクチャ・実装品質 |
| `docs/glossary/infra.md` | インフラ・クラウド・IaC・運用 |
| `docs/glossary/process.md` | Git・レビュー・テスト・スクラム |
| `docs/glossary/ai-agent-ops.md` | セッション運用・委譲・並列実行 |

ユーザーが「その言葉がわからない」と言ったら、標準語に言い換えて答え直す。
そのあと `docs/glossary/jargon.md` に 1 行足す（手順は同ファイルの末尾）。
