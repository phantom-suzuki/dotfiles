# Artifact の作成

## テーマ切り替えボタンを付ける

HTML の Artifact には、ライト / ダークを画面上で切り替える `<button>` を付ける。閲覧者の OS 設定と読みたい見た目が食い違うことがあり、図表やコードを含むページでは見え方の切り替えが読みやすさに直結するため。

- 状態は「システムに従う → ライト → ダーク」の 3 つ。初期状態は閲覧者のテーマを尊重する
- ルート要素の `data-theme` を `light` / `dark` に設定し、システムに従うときは属性を外す。`artifact-design` スキルのトークン設計（素の `:root` がライト、`@media (prefers-color-scheme: dark)` を `:root:not([data-theme="light"])` で囲い、`:root[data-theme="dark"]` で上書き）とそのまま噛み合う
- 選んだ状態を `localStorage` に保存する。読み書きは `try` / `catch` で囲う。復元はページ本文より前のインラインスクリプトで行い、ちらつきを防ぐ
- 現在の状態をアイコンと文字の両方で示し、`aria-label` を付ける。配置はページ上部の右側
- 雛形は `docs/artifact-theme-toggle.md`。片方のテーマだけで成立させる意匠を意図的に選んだときは省略してよく、その理由を 1 行で伝える。Markdown の Artifact は対象外

公開後の共有設定は変更しない。公開直後は本人だけが見られる状態で、必要なら人が共有メニューで設定する。公開時の既定の権限を設定できる公式機能が入ったら、そのときに扱いを決める。
