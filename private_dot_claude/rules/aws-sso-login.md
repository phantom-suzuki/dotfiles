# AWS SSO の期限切れは確認なしでログインし直す

`aws` コマンドが「Token has expired and refresh failed」や「SSO session ... expired」で失敗したら、
ユーザーに聞かずにその場で次を実行する（2026-09-25 のユーザー指示）。

```
aws sso login --profile <失敗したプロファイル>
```

- ブラウザが開き、ユーザーが承認する。承認が要ることは 1 行で伝えてよいが、実行の可否は聞かない
- 実行は背景で始め、ログの `Successfully logged into` と `rc=0` を読んでから元のコマンドをやり直す
- 並列セッション（作業班・検証と台帳）も同じ。リーダーに頼まず自分で実行する。トークンは端末で共有される
- `aws sso logout` や別プロファイルへの切り替えは、この決まりの対象外（確認する）
